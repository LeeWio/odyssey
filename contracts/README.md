# Nexus OpenAPI operation snapshot

`nexus-openapi.operations.json` pins the methods and paths reported by the Nexus Springdoc `/v3/api-docs` integration test. The JSON records the Nexus Git commit, operation IDs and tags. Odyssey CI uses it to detect references to methods or paths the pinned backend does not provide. Payload schema and end-to-end behavior have separate coverage.

To refresh, download the OpenAPI artifact generated by `OpenApiDocumentationIntegrationTest` for the intended Nexus commit. Regenerate the projection and verify it with the frontend checker.

```bash
node scripts/pin-openapi-operations.mjs path/to/nexus-openapi.json NEXUS_COMMIT_SHA > contracts/nexus-openapi.operations.json
bun x prettier --write contracts/nexus-openapi.operations.json
OPENAPI_FILE=contracts/nexus-openapi.operations.json bun run api:coverage
```

Include the change to the pinned contract with the frontend change that consumes the new backend behavior. For interactive checks against a local Nexus instance, run `OPENAPI_URL=http://localhost:8080/v3/api-docs bun run api:contract`.
