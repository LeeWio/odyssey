# 许嵩单曲智能天梯对决（Vae Song Battle）进阶优化蓝图

本规划严格遵循 **Anti-Slop (非套路/防敷衍) 前端设计规范** 与 **Emil Kowalski 的设计工程学**，旨在对已经落地的二分打榜及卡片拖拽对决系统进行更深度的艺术与声学打磨，使其成为兼具极高实用度、声学美感与复古情怀的情怀之作。

---

## 🎯 核心设计目标

让用户不仅仅是在进行冰冷的“做题式”歌曲排序，而是沉浸在**“戴上有线耳机、重温夏天、在宣纸墨迹上抚摸黑胶唱盘”**的视听动三维艺术体验中。

---

## 🌟 五维极致打磨计划 (Five Dimensions of Premium Polish)

### 1. 🎨 墨化扩散与 3D Parallax 卡片悬停

- **3D 卡牌微动 (Parallax Tilt)**：当鼠标在卡片上悬停时，卡片不会生硬放大，而是根据鼠标的实时 `X, Y` 坐标，在三维空间中产生极细微的 **3D 倾斜（Tilt）和折射高光**。手指抓取时，产生轻微物理下陷感。
- **墨斑绽放粒子 (Canvas Ink Paint Splashes)**：当用户向上抛掷卡片，松手判定成功的瞬间，在卡片飞入上方的瞬间，调用一个轻量化的 Canvas 粒子系统，在卡片滑过的地方溅射出 **10-15 颗具有不同黏度和透明度、渐变淡出的水墨晕染粒子**，如同印章在宣纸上重重盖下，墨迹瞬间化开。
- **设计意图**：增加界面的“物质感（Materiality）”，让数字卡牌像实体宣纸卡牌般生动。

### 2. 🔊 怀旧黑胶微杂音与五声调式声景 (Lo-Fi Vinyl Ambient Soundscapes)

- **黑胶底噪 (Vinyl Crackle Static)**：在播放 procedural 音乐盒时，在音频链路中并联一个 **黑胶唱片低频白噪与划痕爆音节点（Vinyl Crackle Generator）**。这是一种极为解压、温暖的白噪音。
- **低通滤波器 (Resonant Low-Pass Filter)**：将音乐盒的 carrier 载波接入一个低通双二阶滤波器（Bi-quad Filter），让声线带上一层淡淡的“闷”（暖糯），听起来就像从一台有年代感的留声机里传出来的声音。
- **设计意图**：用听觉瞬间击中情怀，让 3 秒试听锁不再是门槛，而成为一种享受。

### 3. 📊 对决战况分析与“夙敌”诊断 (completed Scroll Analytics)

- 当用户完成全部二分打榜，金榜诞生时，在卷轴顶部或底部渲染一个“水墨对决战报”折叠区，通过分析历史 ELO 战斗日志和决策秒数，输出极具情怀的趣味统计：
  - **「终极夙敌」**：统计哪两首歌对决次数最多、决策秒数最长、平手机率最高（例如：“_《灰色头像》与《有何不可》缠斗 3 轮，是您最难舍难分的终极夙敌_”）。
  - **「一见倾心」**：统计哪首歌获选最快、决策时间低于 1.5s，说明是秒杀级别的挚爱。
  - **「跌宕起伏 / 黑马」**：统计哪首歌开局由于二分左界落入低位，但后续连续击败高分对手、强势攀升。
- **设计意图**：将数学算法（Binary Tree & ELO）还原为极具可读性和分享欲的人文故事。

### 🖼️ 4. 水墨画意三主题海报生成器 (Canvas Theme Variations)

- 升级现有的 Canvas 海报导出机制，允许用户在同步保存时选择 **三种不同视觉性格的背景与排版主题**：
  1. **《自定义》古籍宣纸（Traditional Parchment）**：当前实现的米黄暖色古籍风格，衬线宋体。
  2. **《寻雾启示》极简墨斑（Minimalist Inkwash）**：冷灰色宣纸、高反差泼墨斑块、现代无衬线体。
  3. **《青年晚报》文艺胶片（Retro Polaroid Film）**：宝丽来拍立得相纸暗框、低饱和度怀旧颗粒、打字机等宽字体。
- **设计意图**：为用户在社交媒体（微博、朋友圈）分享个人金榜提供极其抓人眼球的精美视觉。

### 🔍 5. 滑入落点预测与天梯动画联动 (Ladder Gap Opening Animation)

- 当用户抓起卡片 A 向上拖动准备投票时：
  - 天梯图（实时进度预览）中处于 A 的 **“可能落点区间（`binaryLeft` 到 `binaryRight`）”** 的行与行之间，**物理性地裂开一条缝隙（Gap Expansion）**。
  - 卡片拽得越高，那个缝隙就裂得越明显，暗示“松手后卡牌会飞入这个缝隙”。
- **设计意图**：达成 Emil 规范中极其严格的 **“空间一致性（Spatial Consistency）”**。让用户的拖拽意图在下方的天梯图里得到完美的物理联动映射。

## 📅 落地排期与交付计划 (Milestone Roadmap)

| 阶段        | 交付模块                                  | 关键技术实现                                                                                           | 体验提升指标                             |
| :---------- | :---------------------------------------- | :----------------------------------------------------------------------------------------------------- | :--------------------------------------- |
| **Phase 1** | **天梯开合联动 (Sptial Match)**           | 在天梯预览中通过 `draggedOffset.y` 动态计算目标 `Mid` 左右高度，实现列表 Gap 的平滑撑开过渡动画。      | 消除操作盲区，对决意图完全空间同步。     |
| **Phase 2** | **黑胶底噪与声景调音 (Lo-Fi Audio)**      | 在 `audio.ts` 并入 Web Audio API 的 `BufferSource`（加载一段循环黑胶杂音）与 `BiquadFilterNode`。      | 听觉触感飙升，打造沉浸式复古 Lofi 声景。 |
| **Phase 3** | **墨化粒子与3D卡牌悬停 (Visual Effects)** | 利用 WebGL 或轻量 Canvas 叠加层在 DragEnd 触发粒子，采用 `motion` 的鼠标 `useTransform` 映射 3D 倾斜。 | 触碰数字卡牌如抚摸实体折扇宣纸。         |
| **Phase 4** | **战况夙敌诊断 (Duel Analytics)**         | 提取 `tournamentHistory` 状态日志，计算并翻译“宿敌对决”、“秒杀挚爱”等文学段子并写入卷轴。              | 榜单从单一数据变为充满温度的情怀故事。   |
| **Phase 5** | **Canvas 主题多选海报 (Poster Variety)**  | 在 Canvas 绘图层抽象出 Palette 接口，根据选择的主题（古籍/墨斑/胶片）重绘高分辨率下载图像。            | 激增社交裂变分享欲。                     |
