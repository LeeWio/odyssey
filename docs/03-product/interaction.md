# Interaction

## Current Interaction Model

- motion-led page entry
- card-based scanning
- lightweight navigation
- editorial emphasis over dashboard clutter

## Future Interaction Model

- richer keyboard-first interaction
- faster discovery and filtering
- save / revisit / compare patterns
- clearer state transitions for drafts, published content, and experimental modules

## Interaction Rule

- interactions should reduce effort, not create ceremony
- if an interaction does not help comprehension, retention, or action, it should be removed
