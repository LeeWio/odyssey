# Information Architecture

## Current Structure

- public home experience
- blog index
- article detail view
- supporting product modules
- editor and internal tooling

## Future Structure

- public content layer for readers
- semi-public personal systems for traceable context
- private tools for authoring and capture
- shared primitives for search, identity, and navigation

## IA Rules

- the site should make it obvious what is for reading and what is for interaction
- new content types should be placed in the correct layer, not appended randomly
- navigation should scale as the number of modules grows
