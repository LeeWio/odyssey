# Setup

## Prerequisites

- Node.js compatible runtime for the project toolchain
- Package manager used by the repository

## Common Commands

- `npm run dev` or the repo's preferred equivalent for local development
- run the typecheck and lint commands used by the project before shipping changes

## Working Expectations

- Keep changes small and readable.
- Prefer feature-local edits over cross-cutting rewrites.
- Update docs when a change alters behavior, workflow, or ownership.
