# 许嵩单曲排位战 (Vae Song Battle)

这是一个专门用于对许嵩（Vae）的经典音乐作品进行自定义排名的互动工作台。用户可以通过平滑的拖拽手势或鼠标操作自由调整名次，并为喜爱的歌曲添加个人专属感悟评语。

## 🎨 设计与视觉风格

本项目严格遵循 **Anti-Slop (非套路/防敷衍) 高级前端设计规范** 与 **Emil Kowalski 的设计工程美学**，呈现出如下质感：

1.  **极简文艺复古水墨风 (Minimalist Ink & Wash)**：
    - 摒弃了烂大街的 AI 紫光/渐变霓虹特效，改用温暖内敛的宣纸白（`stone-50`）与深邃的水墨黑（`stone-900`）为主色调，搭配经典灰色系（`stone` 与 `zinc`）。
    - 卡片微边框搭配圆角设计（`rounded-xl`），视觉干净、疏密有度。
2.  **物理级别的按压反馈 (Tactile Feedback)**：
    - 所有的可交互控件（歌曲气泡、排序卡片、关闭按钮等）在按下时（`:active`）都配有微妙的 `scale-[0.95]` 到 `scale-[0.97]` 的物理收缩回弹，让界面产生「正在聆听用户」的灵动质感。
3.  **顺滑的弹簧阻尼排序 (Spring Reorder Physics)**：
    - 工作台排序使用了 `framer-motion` (Motion 12) 提供的重排组件，完美支持移动端触摸与 PC 鼠标操作。
    - 卡片重排时伴有高帧率平滑过渡动画，重排结束松手的一瞬间持久化保存。
4.  **优雅的无 em-dash 设计与极致排版**：
    - 严格执行 **“零破折号（em-dash —）”** 视觉净化指令，使用逗号、括号或微缩标签代替。
    - 单曲专辑标识使用精致的微缩框封装，文字超长自动呈现截断效果（`truncate`），保证即使在 320px 的小屏手机上也不会出现任何排版错位（No wrapped lines for main titles）。

## 🛠 功能模块与使用说明

### 1. 排序工作台 (Workspace Tab)

- **待入榜单歌曲 (Left Column)**：展示未进入你个人排行榜的歌曲气泡。点击任意歌曲即可将其飞入右侧进行排榜。
- **你的专属榜单 (Right Column)**：严格按照 1, 2, 3 等数字名次实时排列。你可以通过拖拽最右侧的 `Grip` (把手图标) 或直接长按整张卡片进行上下位置微调。
- **专属评语添加**：点击任意排榜中的卡片空白区域，即可轻缓弹出编辑面板，可以为您心爱的歌添加私人感悟。

### 2. 音乐排行榜 (Leaderboard Tab)

- **纯享视效榜单**：以极其纯粹、精美的 2/3 列自适应网格展示你排出的 Vae 单曲，包含你的黄金名次角标、歌名、专辑、年份以及专属倾心评语。
- **按专辑筛选**：提供专辑筛选下拉菜单，方便只看《自定义》或《苏格拉没有底》等单张专辑的内部排名。

### 3. 数据备份与管理 (Action Controls)

- **数据导出 (Download JSON)**：一键将你的自定义排榜和评语保存为 `.json` 文件并下载，防止浏览器清空 LocalStorage 后心血白费。
- **数据导入 (Upload JSON)**：一键上传你之前导出的排榜 `.json` 配置文件，无缝恢复你的所有排榜和感悟。
- **清空排名 (Trash)**：重置所有排名数据并彻底清空评语，重新开始你的 Vae 音乐之旅。

## 📂 文件目录结构

为了维护良好的模块化开发习惯，所有相关逻辑均被隔离在 `@app/test/vaesang-battle/` 目录下：

```bash
app/test/vaesang-battle/
├── README.md                 # 本说明文档
├── page.tsx                  # 页面主入口 (负责选项卡切换、导入导出控制等)
├── lib/
│   ├── data.ts               # 初始许嵩单曲库 (包含歌曲名、所属专辑、发行年份等静态数据)
│   └── store.ts              # 核心 Hook，封装 LocalStorage 读写、JSON 导入导出、排序同步等
└── components/
    ├── Workspace.tsx         # 重排工作台组件 (集成 Framer Motion 物理重排)
    ├── Leaderboard.tsx       # 排行榜看板组件 (集成专辑筛选)
    └── EditModal.tsx         # 高级弹射评语编辑弹窗
```
